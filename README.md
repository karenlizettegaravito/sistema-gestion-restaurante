# Sistema Integral de Gestión de Restaurante (SIGR)

## Descripción
El Sistema Integral de Gestión de Restaurante (SIGR) es un proyecto académico individual orientado al desarrollo de una solución digital para facilitar y organizar las operaciones administrativas y operativas de un restaurante.

## Autora
Karen Lizette Garavito Pinzón.

## Objetivo
Desarrollar un sistema que permita gestionar usuarios, consultar el menú, registrar pedidos, administrar reservas y controlar las ventas diarias de un restaurante.

## Módulos del sistema
1. **Gestión de usuarios:** registro y autenticación de clientes, meseros y administradores.
2. **Menú digital:** creación, consulta, actualización y eliminación de platos y categorías.
3. **Gestión de pedidos:** registro y seguimiento de pedidos.
4. **Gestión de reservas:** administración de reservas por fecha y hora.
5. **Caja y ventas:** cierre de caja y generación de reportes diarios.

## Gestión de configuración
El proyecto utiliza Git y GitHub para controlar las versiones del código fuente, registrar los cambios y mantener una línea base estable del software.

## Estado del proyecto
Proyecto individual en fase inicial de desarrollo.
